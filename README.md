➤ Interactive JavaScript Quiz Application

✦ An interactive, responsive single-page web application designed to test core web development knowledge. Built using modern modular JavaScript (ES6+), Bootstrap 5, and custom CSS transitions.

✨ Features

➥ Dynamic Rendering: Loads question texts and option choices completely on the fly via DOM manipulation—zero hardcoded options in the HTML.

➥ Real-time Visual Feedback: Instantly highlights chosen options (Green for correct, Red for wrong) and automatically reveals the correct answer on wrong selections.

➥ Smart Option Locking: Disables choices after selection while keeping your pick vibrant at 100% opacity.

➥ Animated State Transitions: Uses custom cubic-bezier animations (smoothReveal) for smooth text transitions, progress displays, and UI state updates.

➥ Live Score & Visual Progress Ring: Tracks user performance with a dynamic SVG circular progress ring and tailored performance feedback.

➥ Full Reset Functionality: Allows users to seamlessly restart the quiz from the final screen without reloading the page.


🛠️ Built With

✪ HTML5: Structural layout and semantic markup.

✪ CSS3 & Bootstrap 5: Custom styling, flexbox alignment, and responsive utility classes.

✪ JavaScript (ES6 Modules): Dynamic DOM manipulation, event handling, state tracking, and timed visual execution loops.
